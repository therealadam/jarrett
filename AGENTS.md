# Jarrett

A Micro.blog theme. See README.md for layout and options.

## After pushing to `main`

Micro.blog does not pick up GitHub changes on its own (the Themes API can't refresh a theme from GitHub; see Linear CAL-63). After changes land on `main`, remind the human to finish the deploy:

1. Open https://micro.blog/account/themes/106128/templates/blank?site_id=151691&q=&view=folders
2. Click **Pull from GitHub**.

Agents can't do this step. Don't report a theme change as live until the human has done it.
